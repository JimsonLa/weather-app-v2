# weather-app-v2 🌦️

Une application web météo permettant d'afficher la météo actuelle d'une ville via l'API OpenWeatherMap.

---

## 🚀 Fonctionnalités
- Recherche de ville
- Affichage de la température et de la météo
- Données récupérées depuis une API

---

## 🛠️ Technologies
- HTML
- CSS
- JavaScript
- OpenWeatherMap API

---

## 🔑 Configuration
Ce projet nécessite une clé API OpenWeatherMap.

Dans le fichier script.js :

const API_KEY = "YOUR_API_KEY";

---

## ▶️ Lancer le projet
1. Cloner le repository
2. Ouvrir index.html dans un navigateur
